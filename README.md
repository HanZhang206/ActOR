# ActOR project page

Website for **ActOR: Ambient AI-Based Agentic Orchestration for Humanoid Autonomy in Operating Rooms**.

The page is built with the [academic project Astro template](https://github.com/RomanHauksson/academic-project-astro-template). The layout follows the earlier static page in `../actor-project-page`.

## Preview

Requires Node.js 24.

```bash
npm install
npm run dev
```

Open http://localhost:4321.

Edit the text, authors, figures, and videos in `src/paper.mdx`. Images live in `src/assets/`. Videos, posters, and PDFs live in `public/`.

## Build

```bash
npm run build
```

The static site is written to `dist/`.
